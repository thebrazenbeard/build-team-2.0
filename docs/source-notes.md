# Source Notes

The project borrows a conceptual pattern from the Generative Agents research implementation:

- perceive current context;
- retrieve relevant prior information;
- plan;
- reflect;
- execute.

Build Team 2.0 changes the unit of identity and storage. It uses one collective memory and ten stable cognitive lenses rather than independent simulated people with separate autobiographical memory streams. The original Smallville environment, spatial navigation, sprites, and legacy 2023 dependency stack are not used.

The Generative Agents repository is Apache-2.0 licensed. This repository includes attribution in `NOTICE` but does not copy its source code.
