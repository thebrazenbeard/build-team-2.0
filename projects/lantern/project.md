# Project Lantern

Status: STRUCTURE_INITIALIZATION
Coordinator: One
Project key: `lantern`

## Objective

Build a local-first, provenance-aware research and decision system for long-running technical projects.

Lantern will preserve the distinction among evidence, claims, ideas, contradictions, decisions, temporal states, implementation artifacts, and validation receipts. It will help an operator answer what is believed, why it is believed, what conflicts with it, what changed, and what remains unverified.

## Current phase

Structure only. No facet workflow has been assigned.

## Authority boundaries

Merge, deployment, credentials, paid infrastructure, production mutation, destructive action, canonical-memory promotion, and scheduled automation remain user-only gates.

## Project surfaces

- Shared knowledge: `shared/knowledge/`
- Shared ideas: `shared/ideas/`
- Facet workspaces: `workstreams/`
- Reviews: `reviews/`
- Candidate and accepted artifacts: `artifacts/`
- Historical material: `archive/`

## Initial acceptance criteria

Before workflow assignment:

1. the project manifest exists;
2. shared knowledge and ideas indexes exist;
3. all ten facet workstream folders exist;
4. review, artifact, and archive surfaces exist;
5. the complete structure is read back from one exact GitHub head;
6. no Lantern assignment has been dispatched.
